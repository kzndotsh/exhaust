# Untrusted Target output is delimited distinctly in agent prompts

Any content that originates from the Target itself (an HTTP response body, an error page, a header, log output) is wrapped in a distinct, nonce-style delimiter when it is placed into an agent's prompt, so the agent has an explicit signal that this text is data from the thing under attack, never an instruction to follow.

Exhaust's agent actively probes a live Target and reads back whatever that Target returns. A Target is not a passive source file; it is attacker-controlled by construction, and a real pentest surface already includes planting a prompt injection in an application's own responses to confuse the attacking agent. Anthropic's reference harness already carries this exact pattern (a dedicated module for untrusted-content delimiters) for a narrower reason (keeping tool output distinct from instructions); exhaust needs it for a stronger one, since the Target is specifically trying to be hostile toward whatever reads its output, including our own agent.

A widely used, heavily cited prompt-engineering reference makes the reason this has to be a structural delimiter, not a prompt-level instruction, explicit: it surveys the field's own defense tactics against prompt injection and states plainly that instructing the model to ignore injected content "is not a complete solution or offers any guarantees," with no widely accepted technique that reliably defeats a text-based injection through instruction alone. The same source draws the correct analogy on its own: prompt injection resembles SQL injection, and the fix that actually works there is parameterization, keeping instructions and untrusted input in genuinely separate channels rather than trusting the model to tell them apart inside one blended prompt. This is exactly why exhaust's delimiter has to be paired with the instruction-source-boundary rule the agent is actually built to follow (never execute an instruction that arrives inside Target output, regardless of framing), not offered as a defense on its own; a delimiter marks the boundary, it doesn't enforce it.
