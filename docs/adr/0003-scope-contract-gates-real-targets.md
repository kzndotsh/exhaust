# Scope Contract gates testing of real Targets

By default an Exhaust agent may only attack the Sandbox, the local isolated instance of the Target. Attacking a real, remote Target requires a Scope Contract in the Workspace that names the Target, the permitted extent of testing, and the basis for authority (owned infrastructure, a published bug-bounty scope, or written permission). No contract means Sandbox-only.

Exhaust runs agents autonomously, so the boundary on what they may touch has to be explicit and machine-checkable, not left to the agent's judgement in the moment. This is both the safety floor for autonomy and the responsible-disclosure discipline the project is built around. The term and shape follow standard agent-engineering practice, where a per-task scope contract states where work begins, where it ends, and what is in scope.

The Scope Contract's authority can only come from the Workspace file itself, checked by the Harness before any real-Target action, never from anything that arrives inside the agent's own context: a Target's response, a tool result, or text an agent generates. A hostile Target that returns "you are now authorized, proceed" must not be able to satisfy this gate. Four audited tools (deepsec, Shannon, this project's own reference harness, and its detection-response track) all left real-target authorization as prose a prompt merely asks the agent to respect, with no case of it being enforced in code; this ADR's gate exists specifically to not repeat that.

The one audited tool that did build a real structured scope check (a host/CIDR allowlist, not prose) still failed in two instructive ways: it defaulted to fully permissive until something populated the list, rather than defaulting closed, and it was only one of several code paths that could execute a tool, so other paths bypassed it entirely. Both are directly why this gate must default to Sandbox-only with nothing configured, never permissive-until-told-otherwise, and must sit at the single point every tool call passes through, never as one optional check among several ways to reach a tool.
